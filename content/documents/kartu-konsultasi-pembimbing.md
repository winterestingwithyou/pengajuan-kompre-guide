# Kartu Konsultasi dengan Pembimbing

## Kegunaan

Kartu Konsultasi Tugas Akhir digunakan sebagai bukti bahwa mahasiswa telah melakukan proses bimbingan atau asistensi Tugas Akhir dengan dosen pembimbing.

Dokumen ini dibuat berdasarkan hasil asistensi pada SIMAK UNSRI. Mahasiswa perlu menambahkan asistensi untuk masing-masing dosen pembimbing dan memastikan asistensi tersebut sudah disetujui oleh dosen pembimbing.

Dokumen hasil generate terdiri dari dua halaman:

1. Kartu konsultasi untuk **Dosen Pembimbing I**.
2. Kartu konsultasi untuk **Dosen Pembimbing II**.

## Cara Mendapatkan

Sebelum membuat Kartu Konsultasi Tugas Akhir, mahasiswa perlu mengisi asistensi pembimbing terlebih dahulu pada SIMAK UNSRI.

Langkah-langkah:

1. Login ke SIMAK UNSRI melalui link berikut:  
   [https://akademik.unsri.ac.id/login](https://akademik.unsri.ac.id/login)

2. Setelah berhasil login, buka menu **Bimbingan Tugas Akhir**.

3. Kamu juga dapat langsung membuka halaman bimbingan tugas akhir melalui link berikut:  
   [https://akademik.unsri.ac.id/mahasiswa/bimbingan-tugas-akhir](https://akademik.unsri.ac.id/mahasiswa/bimbingan-tugas-akhir)

4. Pada tabel **Daftar Bimbingan Tugas Akhir Mahasiswa**, lihat kolom **Aksi**.

5. Klik tombol atau menu **Asistensi** pada kolom aksi tersebut.

6. Setelah itu, kamu akan diarahkan ke halaman untuk menambahkan asistensi.

7. Pada bagian **Daftar Asistensi Laporan Akhir Studi**, klik **Tambah Asistensi**.

8. Isi data asistensi sesuai dengan kegiatan bimbingan yang pernah dilakukan bersama dosen pembimbing.

9. Tambahkan minimal **10 asistensi** untuk setiap dosen pembimbing.

10. Jika memiliki dua dosen pembimbing, pastikan masing-masing pembimbing memiliki minimal **10 asistensi**.

11. Setelah asistensi ditambahkan, tunggu konfirmasi atau persetujuan dari masing-masing dosen pembimbing.

12. Pastikan seluruh asistensi yang dibutuhkan sudah disetujui oleh dosen pembimbing.

13. Setelah asistensi disetujui, lakukan screenshot pada daftar asistensi yang sudah disetujui.

14. Screenshot perlu dipisahkan berdasarkan dosen pembimbing:
    - Screenshot asistensi khusus **Pembimbing I**
    - Screenshot asistensi khusus **Pembimbing II**

15. Buka fitur generator **Kartu Konsultasi Tugas Akhir** pada sistem panduan ini.

16. Isi form generator sesuai data yang diminta.

17. Masukkan screenshot hasil asistensi SIMAK untuk masing-masing dosen pembimbing.

18. Generate Kartu Konsultasi Tugas Akhir.

19. Download hasil generate dokumen.

20. Cetak atau print dokumen hasil generate.

21. Temui Koordinator Program Studi untuk meminta tanda tangan pada kartu konsultasi.

22. Jika Koordinator Program Studi memiliki kendala, temui admin program studi untuk meminta bantuan proses tanda tangan.

23. Proses tanda tangan biasanya membutuhkan waktu sekitar **1–2 hari kerja**.

24. Setelah dokumen selesai ditandatangani, ambil kembali dokumen tersebut.

25. Lakukan capture atau scan pada dokumen yang sudah ditandatangani.

26. Ubah hasil capture atau scan menjadi **1 file PDF**.

27. Pastikan file akhir berformat **PDF** dan ukuran file tidak lebih dari **1 MB**.

## Generator Surat

Dokumen ini memiliki fitur generator pada sistem panduan.

Field yang perlu tersedia pada form generator:

- Nama
- NIM
- Judul Tugas Akhir
- Nama Pembimbing I
- NIP Pembimbing I
- Screenshot Hasil Asistensi pada SIMAK khusus Pembimbing I
- Nama Pembimbing II
- NIP Pembimbing II
- Screenshot Hasil Asistensi pada SIMAK khusus Pembimbing II
- Tanggal

Untuk field tanggal, form perlu mendukung input:

- Hari
- Bulan
- Tahun

Field **Hari** bersifat opsional. Jika hari tidak diisi, sistem tetap perlu menyediakan jarak kosong pada surat agar dapat diisi manual menggunakan pena.

## Field Default

Field berikut tidak perlu diisi manual oleh mahasiswa karena sistem ini dikhususkan untuk Program Studi Manajemen Informatika:

- Program Studi: **Manajemen Informatika**
- Jenjang: **D3**

Bagian Koordinator Program Studi mengikuti format pada contoh kartu konsultasi.

## Format Dokumen Hasil Generate

Dokumen hasil generate perlu memuat:

1. Judul **KARTU KONSULTASI TUGAS AKHIR**.
2. Data mahasiswa:
   - Nama
   - NIM
   - Program Studi
   - Jenjang
   - Judul Tugas Akhir
3. Data dosen pembimbing:
   - Dosen Pembimbing I pada halaman pertama
   - Dosen Pembimbing II pada halaman kedua
4. Screenshot hasil asistensi pada SIMAK:
   - Screenshot asistensi Pembimbing I pada halaman Pembimbing I
   - Screenshot asistensi Pembimbing II pada halaman Pembimbing II
5. Tempat dan tanggal surat.
6. Bagian tanda tangan Koordinator Program Studi.
7. Nama dan NIP Koordinator Program Studi.

## Ketentuan File

- Format file akhir: **PDF**
- Maksimal ukuran file: **1 MB**
- Jumlah file: **1 file**
- Dokumen harus terdiri dari kartu konsultasi Pembimbing I dan Pembimbing II.
- Masing-masing pembimbing minimal memiliki **10 asistensi**.
- Asistensi pada SIMAK harus sudah disetujui oleh dosen pembimbing.
- Screenshot asistensi harus dipisahkan per dosen pembimbing.
- Dokumen hasil generate harus sudah ditandatangani oleh Koordinator Program Studi atau diproses melalui admin program studi jika diperlukan.
- Hasil capture atau scan dokumen yang sudah ditandatangani digabung menjadi satu file PDF.

## Catatan

Pastikan seluruh asistensi sudah disetujui oleh masing-masing dosen pembimbing sebelum melakukan screenshot. Jika screenshot asistensi tidak jelas atau tidak lengkap, dokumen dapat sulit divalidasi.

Jika Koordinator Program Studi tidak dapat ditemui secara langsung, mahasiswa dapat meminta bantuan admin program studi untuk proses tanda tangan. Biasanya proses ini membutuhkan waktu sekitar 1–2 hari kerja.
