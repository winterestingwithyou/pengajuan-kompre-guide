# DKN yang Sudah Keluar Semua Nilai Kecuali Projek Akhir

## Kegunaan

DKN digunakan sebagai dokumen akademik yang menunjukkan bahwa seluruh nilai mahasiswa sudah keluar, kecuali nilai Projek Akhir.

Dokumen ini menjadi salah satu syarat penting dalam pengajuan kompre. DKN yang dikumpulkan harus sudah dicetak dan dicap oleh pihak terkait.

## Cara Mendapatkan

DKN dapat diajukan melalui spreadsheet pengajuan Cetak DKN untuk Kompre. Setelah pengajuan disetujui oleh admin, mahasiswa dapat mengambil hasil cetak DKN melalui admin Pusat Pelayanan Terpadu (PPT).

Langkah-langkah:

1. Buka spreadsheet pengajuan Cetak DKN untuk Kompre melalui link berikut:  
   [https://docs.google.com/spreadsheets/d/1XulVzq8kPr_V5OXYLgs-vV2bxDe2alukgSpubOLYgUs/edit?usp=drive_link](https://docs.google.com/spreadsheets/d/1XulVzq8kPr_V5OXYLgs-vV2bxDe2alukgSpubOLYgUs/edit?usp=drive_link)

2. Tambahkan baris baru pada spreadsheet tersebut.

3. Isi data yang diminta pada kolom yang tersedia, yaitu:
   - Nama
   - NIM
   - Tanggal pengajuan
   - Jurusan atau Program Studi
   - Nomor HP

4. Setelah mengisi data, tunggu proses pengecekan dari admin.

5. Perhatikan kolom **Keterangan** pada spreadsheet.

6. Kolom **Keterangan** akan diisi oleh admin dengan status seperti **approved** atau **not approved**.

7. Tunggu sekitar **1–3 hari** setelah melakukan pengisian data sampai kolom **Keterangan** bernilai **approved**.

8. Jika status sudah **approved**, temui admin bagian **Pusat Pelayanan Terpadu (PPT)** di lantai 1 Gedung Diklat Fasilkom UNSRI Bukit.

9. Sampaikan bahwa kamu ingin mencetak DKN untuk keperluan kompre.

10. DKN akan dicetak oleh admin PPT. Mahasiswa cukup menerima dokumen yang sudah dicetak.

11. DKN yang diberikan oleh admin sudah dalam kondisi dicap.

12. Setelah menerima DKN, lakukan capture atau scan dokumen tersebut.

13. Ubah hasil capture atau scan menjadi file PDF.

14. Pastikan file akhir berformat **PDF** dan ukuran file tidak lebih dari **1 MB**.

## Jika Belum Approved Setelah 3 Hari

Jika setelah lebih dari 3 hari kolom **Keterangan** masih kosong atau belum diperbarui oleh admin, mahasiswa dapat langsung menemui admin **Pusat Pelayanan Terpadu (PPT)** di lantai 1 Gedung Diklat Fasilkom UNSRI Bukit.

Sampaikan bahwa kamu sudah mengisi spreadsheet pengajuan Cetak DKN untuk Kompre, tetapi status pada kolom **Keterangan** belum berubah. Setelah itu, minta bantuan admin PPT untuk mencetak DKN secara langsung.

## Ketentuan File

- Format file: **PDF**
- Maksimal ukuran file: **1 MB**
- Jumlah file: **1 file**
- DKN harus sudah dicetak dan dicap.
- File PDF dibuat dari hasil capture atau scan DKN yang diterima dari admin.

## Catatan

Pastikan data yang diisi pada spreadsheet sudah benar, terutama nama, NIM, jurusan atau program studi, tanggal pengajuan, dan nomor HP. Jika status pengajuan tidak berubah setelah 3 hari, segera temui admin PPT agar proses cetak DKN dapat dibantu secara langsung.
