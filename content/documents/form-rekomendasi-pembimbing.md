# Form Rekomendasi dari Kedua Pembimbing untuk Ujian Komprehensif

## Kegunaan

Form rekomendasi pembimbing digunakan sebagai bukti bahwa mahasiswa telah mendapatkan persetujuan dari pembimbing untuk mengikuti ujian komprehensif atau ujian proyek akhir.

Dokumen ini terdiri dari dua surat rekomendasi, yaitu:

1. Surat rekomendasi dari **Pembimbing I**.
2. Surat rekomendasi dari **Pembimbing II**.

Kedua surat tersebut perlu ditandatangani oleh masing-masing pembimbing, kemudian digabungkan menjadi satu file PDF.

## Cara Mendapatkan

Form rekomendasi pembimbing dapat dibuat melalui fitur generator surat pada sistem panduan ini.

Langkah-langkah:

1. Buka fitur generator **Surat Rekomendasi Ujian Proyek Akhir** pada sistem panduan ini.

2. Isi form generator sesuai data yang diminta.

3. Pastikan data mahasiswa dan data pembimbing sudah benar sebelum melakukan generate surat.

4. Generate surat rekomendasi ujian proyek akhir.

5. Sistem akan menghasilkan dua halaman surat:
   - Halaman untuk **Pembimbing I**
   - Halaman untuk **Pembimbing II**

6. Download hasil generate surat rekomendasi tersebut.

7. Cetak atau print surat hasil generate.

8. Temui **Pembimbing I** untuk meminta tanda tangan pada surat rekomendasi Pembimbing I.

9. Temui **Pembimbing II** untuk meminta tanda tangan pada surat rekomendasi Pembimbing II.

10. Setelah kedua surat sudah ditandatangani oleh masing-masing pembimbing, ambil kembali surat tersebut.

11. Lakukan capture atau scan terhadap kedua surat yang sudah ditandatangani.

12. Gabungkan hasil capture atau scan kedua surat tersebut menjadi **1 file PDF**.

13. Pastikan file akhir berformat **PDF** dan ukuran file tidak lebih dari **1 MB**.

## Generator Surat

Dokumen ini memiliki fitur generator surat pada sistem panduan.

Field yang perlu tersedia pada form generator:

- Nama
- NIM
- Judul Tugas Akhir
- Nama Pembimbing I
- NIP Pembimbing I
- Nama Pembimbing II
- NIP Pembimbing II
- Tanggal

Untuk field tanggal, form perlu mendukung input:

- Hari
- Bulan
- Tahun

Field **Hari** bersifat opsional. Jika hari tidak diisi, sistem tetap perlu menyediakan jarak kosong pada surat agar dapat diisi manual menggunakan pena.

## Field Default

Field berikut tidak perlu diisi manual oleh mahasiswa karena sistem ini dikhususkan untuk Program Studi Manajemen Informatika:

- Fakultas: **Ilmu Komputer**
- Program Studi: **Manajemen Informatika**
- Jenjang: **D3**

## Format Surat Hasil Generate

Surat hasil generate perlu memuat:

1. Judul **SURAT REKOMENDASI UJIAN PROYEK AKHIR**.
2. Data mahasiswa:
   - Nama
   - NIM
   - Fakultas
   - Program Studi
   - Jenjang
   - Judul Tugas Akhir
3. Pernyataan bahwa mahasiswa telah memenuhi persyaratan dan dapat mengikuti Ujian Proyek Akhir.
4. Tahun akademik.
5. Tempat dan tanggal surat.
6. Bagian tanda tangan **Pembimbing I** pada halaman pertama.
7. Bagian tanda tangan **Pembimbing II** pada halaman kedua.
8. Nama dan NIP masing-masing pembimbing.

## Link Terkait

Tidak ada link eksternal khusus untuk dokumen ini. Surat dibuat melalui generator pada sistem panduan ini, lalu ditandatangani oleh masing-masing pembimbing.

## Ketentuan File

- Format file akhir: **PDF**
- Maksimal ukuran file: **1 MB**
- Jumlah file: **1 file**
- Surat harus terdiri dari rekomendasi Pembimbing I dan Pembimbing II.
- Kedua surat harus sudah ditandatangani oleh masing-masing pembimbing.
- Hasil capture atau scan kedua surat digabung menjadi satu file PDF.

## Catatan

Pastikan nama pembimbing, NIP pembimbing, judul tugas akhir, dan data mahasiswa sudah benar sebelum surat dicetak. Jika bagian hari pada tanggal belum ingin diisi melalui sistem, bagian tersebut dapat dikosongkan agar bisa diisi manual menggunakan pena.
