# Bukti Slip Pembayaran UKT dari Semester 1 Sampai Semester Terakhir

## Kegunaan

Bukti Slip Pembayaran UKT digunakan sebagai dokumen pendukung yang menunjukkan riwayat pembayaran UKT mahasiswa dari semester awal sampai semester terakhir.

Dokumen ini dikumpulkan dalam bentuk **1 file PDF** yang berisi seluruh bukti atau slip pembayaran UKT yang diperlukan.

Jika mahasiswa merupakan penerima atau mahasiswa terdaftar KIPK, dokumen yang dilampirkan dapat berupa **SK KIPK** yang memuat nama mahasiswa.

## Cara Mendapatkan

Dokumen ini dapat disiapkan dari bukti atau slip pembayaran UKT yang dimiliki mahasiswa dari semester 1 sampai semester terakhir.

Langkah-langkah:

1. Kumpulkan seluruh bukti atau slip pembayaran UKT dari semester 1 sampai semester terakhir.

2. Pastikan setiap bukti pembayaran terlihat jelas, terutama bagian:
   - Nama mahasiswa
   - NIM jika tersedia
   - Semester pembayaran
   - Nominal pembayaran
   - Status atau bukti pembayaran

3. Jika bukti pembayaran masih berbentuk fisik, lakukan capture atau foto pada setiap bukti pembayaran.

4. Jika bukti pembayaran sudah berbentuk digital, gunakan file atau screenshot bukti pembayaran tersebut.

5. Susun seluruh bukti pembayaran UKT dari semester awal sampai semester terakhir.

6. Gabungkan seluruh hasil capture, foto, screenshot, atau file bukti pembayaran menjadi **1 file PDF**.

7. Pastikan file akhir berformat **PDF**.

8. Pastikan ukuran file tidak lebih dari **10 MB**.

## Untuk Mahasiswa KIPK

Jika kamu merupakan mahasiswa terdaftar KIPK, lampirkan **SK KIPK** yang terdapat nama kamu di dalamnya.

Langkah-langkah:

1. Buka folder SK KIPK melalui link berikut:  
   [https://drive.google.com/drive/folders/1h7Bkp2UCqIRnu8ZObW3v4-N89qS5p8L4?usp=sharing](https://drive.google.com/drive/folders/1h7Bkp2UCqIRnu8ZObW3v4-N89qS5p8L4?usp=sharing)

2. Cari SK KIPK yang sesuai dengan data kamu.

3. Pastikan nama kamu tercantum pada SK KIPK tersebut.

4. Download SK KIPK yang sesuai.

5. Jika SK KIPK sudah berbentuk PDF, gunakan file tersebut.

6. Jika SK KIPK masih berupa gambar atau hasil capture, ubah menjadi file PDF.

7. Pastikan file akhir berformat **PDF** dan ukuran file tidak lebih dari **10 MB**.
