# KRS dari Semester 1 Sampai Terakhir

## Kegunaan

KRS dari semester 1 sampai semester terakhir digunakan sebagai dokumen akademik yang menunjukkan riwayat pengambilan mata kuliah mahasiswa selama masa perkuliahan.

Dokumen ini harus berisi seluruh KRS dari semester awal sampai semester terakhir yang diminta, sudah dicap oleh pihak program studi, dan digabungkan ke dalam satu file PDF.

## Cara Mendapatkan

KRS dapat diunduh melalui sistem akademik UNSRI, kemudian dicetak dan dimintakan cap ke admin program studi.

Langkah-langkah:

1. Buka sistem akademik UNSRI melalui link berikut:  
   [https://akademik.unsri.ac.id](https://akademik.unsri.ac.id)

2. Login menggunakan akun mahasiswa.

3. Setelah berhasil login, buka menu **Kartu Rencana Studi**.

4. Kamu juga dapat langsung membuka halaman KRS melalui link berikut:  
   [https://akademik.unsri.ac.id/mahasiswa/perkuliahan/krs](https://akademik.unsri.ac.id/mahasiswa/perkuliahan/krs)

5. Download semua file PDF KRS dari semester awal sampai semester terakhir yang dibutuhkan, misalnya semester 1 sampai semester 6.

6. Cetak atau print semua KRS yang sudah diunduh.

7. Jika kamu sudah memiliki KRS versi cetak, gunakan KRS cetak tersebut dan tidak perlu mencetak ulang.

8. Cetak hanya KRS yang memang belum tersedia dalam bentuk cetak.

9. Setelah semua KRS tersedia dalam bentuk cetak, temui admin program studi untuk meminta cap pada dokumen KRS.

10. Tunggu proses pemberian cap oleh admin program studi. Biasanya proses ini membutuhkan waktu sekitar **1–2 hari kerja**.

11. Setelah KRS selesai dicap, ambil kembali dokumen tersebut dari admin program studi.

12. Capture atau scan setiap lembar KRS yang sudah dicap.

13. Gabungkan seluruh hasil capture atau scan KRS ke dalam satu file PDF.

14. Pastikan file akhir berformat **PDF** dan hanya terdiri dari **1 file**.

## Ketentuan File

- Format file: **PDF**
- Maksimal ukuran file: **10 MB**
- Jumlah file: **1 file**
- Semua KRS dari semester awal sampai semester terakhir harus digabung dalam satu PDF.
- KRS harus sudah diberi cap oleh admin program studi.

## Catatan

Jika kamu sudah memiliki KRS yang telah dicetak sebelumnya, gunakan dokumen tersebut agar tidak perlu mencetak ulang. Namun, pastikan seluruh KRS yang dikumpulkan sudah lengkap, sudah dicap, dan telah digabung menjadi satu file PDF.
