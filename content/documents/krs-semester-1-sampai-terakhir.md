# KRS dari Semester 1 Sampai Terakhir

## Kegunaan

KRS dari semester 1 sampai semester terakhir digunakan sebagai dokumen akademik yang menunjukkan riwayat pengambilan mata kuliah mahasiswa selama masa perkuliahan.

Dokumen ini harus berisi seluruh KRS dari semester yang diminta (umumnya semester 1 sampai semester 6) dan digabungkan ke dalam satu file PDF tanpa cap.

## Cara Mendapatkan

KRS dapat diunduh langsung melalui sistem akademik UNSRI, lalu digabungkan ke dalam satu file PDF tanpa perlu dicap.

Langkah-langkah:

1. Buka sistem akademik UNSRI melalui link berikut:  
   [https://akademik.unsri.ac.id](https://akademik.unsri.ac.id)

2. Login menggunakan akun mahasiswa.

3. Setelah berhasil login, buka menu **Kartu Rencana Studi**.

4. Kamu juga dapat langsung membuka halaman KRS melalui link berikut:  
   [https://akademik.unsri.ac.id/mahasiswa/perkuliahan/krs](https://akademik.unsri.ac.id/mahasiswa/perkuliahan/krs)

5. Download semua file PDF KRS dari semester yang diminta, misalnya semester 1 sampai semester 6.

6. Gabungkan semua file KRS tersebut menjadi satu file PDF.

7. Pastikan file akhir berformat **PDF** dan hanya terdiri dari **1 file**.

## Link Terkait

- Sistem Akademik UNSRI: [https://akademik.unsri.ac.id](https://akademik.unsri.ac.id)
- Halaman KRS SIMAK UNSRI: [https://akademik.unsri.ac.id/mahasiswa/perkuliahan/krs](https://akademik.unsri.ac.id/mahasiswa/perkuliahan/krs)

## Ketentuan File

- Format file: **PDF**
- Maksimal ukuran file: **10 MB**
- Jumlah file: **1 file**
- Semua KRS dari semester yang diminta (umumnya semester 1 sampai semester 6) harus digabung dalam satu PDF.
- KRS tidak wajib diberi cap.

## Catatan

Pastikan seluruh KRS yang dikumpulkan sudah lengkap sesuai semester yang diminta (umumnya semester 1 sampai semester 6) dan telah digabung menjadi satu file PDF tanpa cap.
