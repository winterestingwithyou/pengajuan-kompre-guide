# SULIET Minimal Score 400

## Kegunaan

SULIET atau USEPT digunakan sebagai bukti bahwa mahasiswa telah memenuhi syarat kemampuan bahasa Inggris dengan skor minimal **400**.

Istilah **SULIET** merupakan istilah lama. Saat ini, dokumen atau nilai yang digunakan mengacu pada **USEPT**, yaitu tes kemampuan bahasa Inggris khusus UNSRI.

Untuk pengajuan kompre, mahasiswa perlu menyiapkan surat validasi USEPT yang telah divalidasi oleh admin program studi dan koordinator program studi. Koordinator program studi juga dapat disebut sebagai kepala program studi.

## Cara Mendapatkan

Sebelum membuat surat validasi USEPT, pastikan kamu sudah lulus tes USEPT dengan skor minimal **400**.

Langkah-langkah:

1. Pastikan kamu telah mengikuti dan lulus tes USEPT dengan skor minimal **400**.

2. Login ke SIMAK UNSRI melalui link berikut:  
   [https://akademik.unsri.ac.id/login](https://akademik.unsri.ac.id/login)

3. Setelah berhasil login, buka menu **Nilai USEPT**.

4. Kamu juga dapat langsung membuka halaman nilai USEPT melalui link berikut:  
   [https://akademik.unsri.ac.id/mahasiswa/perkuliahan/nilai-usept](https://akademik.unsri.ac.id/mahasiswa/perkuliahan/nilai-usept)

5. Lakukan screenshot pada halaman nilai USEPT tersebut.

6. Pastikan bagian **Daftar Nilai Tes USEPT** terlihat dengan jelas pada hasil screenshot.

7. Screenshot harus menampilkan informasi penting berikut:
   - Nama
   - NIM
   - Tanggal ujian
   - Skor USEPT
   - Status lulus

8. Pastikan skor USEPT yang terlihat pada screenshot minimal **400** dan statusnya **lulus**.

9. Buka fitur generator **Surat Validasi USEPT** pada sistem panduan ini.

10. Isi form generator sesuai data yang diminta.

11. Upload atau masukkan screenshot USEPT dari SIMAK pada form generator.

12. Generate surat validasi USEPT.

13. Download hasil generate surat validasi USEPT.

14. Cetak atau print surat validasi USEPT yang sudah digenerate.

15. Temui admin program studi dan koordinator program studi untuk meminta validasi.

16. Jika koordinator program studi memiliki kendala, kamu dapat meminta bantuan admin program studi untuk melakukan validasi pada bagian koordinator program studi.

17. Tunggu proses validasi. Biasanya proses ini membutuhkan waktu sekitar **1–2 hari kerja**.

18. Admin dapat memberi tahu kapan surat validasi USEPT bisa diambil.

19. Setelah surat selesai divalidasi, temui admin kembali untuk mengambil surat tersebut.

20. Lakukan capture atau scan pada surat yang sudah divalidasi.

21. Ubah hasil capture atau scan menjadi file **PDF**.

22. Pastikan file akhir berformat **PDF** dan ukuran file tidak lebih dari **1 MB**.

## Generator Surat

Dokumen ini memiliki fitur generator surat validasi USEPT pada sistem panduan.

Field yang perlu tersedia pada form generator:

- Nama
- NIM
- Screenshot USEPT pada SIMAK

Field yang tidak perlu diisi manual oleh mahasiswa:

- Fakultas
- Program Studi
- Admin Program Studi
- Koordinator Program Studi

Nilai default yang digunakan:

- Fakultas: **Ilmu Komputer**
- Program Studi: **Manajemen Informatika**

Data admin program studi dan koordinator program studi mengikuti format pada contoh surat validasi USEPT.

## Format Surat Hasil Generate

Surat hasil generate perlu memuat:

1. Judul **VALIDASI USEPT**.
2. Data mahasiswa:
   - Nama
   - NIM
   - Fakultas
   - Program Studi
3. Screenshot halaman nilai USEPT dari SIMAK.
4. Bagian tanda tangan atau validasi:
   - Admin Program Studi
   - Koordinator Program Studi
5. Nama dan NIP admin program studi.
6. Nama dan NIP koordinator program studi.

## Ketentuan File

- Format file akhir: **PDF**
- Maksimal ukuran file: **1 MB**
- Jumlah file: **1 file**
- Surat validasi USEPT harus sudah divalidasi oleh admin program studi dan koordinator program studi.
- Screenshot nilai USEPT harus terlihat jelas.
- Skor USEPT harus minimal **400**.
- Status USEPT harus **lulus**.

## Catatan

Pastikan screenshot halaman nilai USEPT dari SIMAK terlihat jelas sebelum digunakan pada generator surat. Bagian yang paling penting adalah tabel atau daftar nilai USEPT yang menampilkan nama, NIM, tanggal ujian, skor USEPT, dan status kelulusan.

Jika koordinator program studi tidak dapat melakukan validasi secara langsung, mahasiswa dapat meminta bantuan admin program studi untuk memproses validasi pada bagian koordinator program studi.
