# Surat Keterangan Bebas Pembayaran Apapun

## Kegunaan

Surat Keterangan Bebas Pembayaran digunakan sebagai bukti bahwa mahasiswa tidak memiliki tanggungan pembayaran yang perlu diselesaikan.

Dokumen ini diajukan melalui sistem **Online Letter Service (OLS) Fasilkom UNSRI**. Setelah pengajuan diproses dan selesai, surat dapat diunduh langsung dari OLS dalam format PDF.

## Cara Mendapatkan

Surat ini dapat diajukan melalui OLS Fasilkom UNSRI.

Langkah-langkah:

1. Buka website OLS Fasilkom UNSRI melalui link berikut:  
   [https://ols.ilkom.unsri.ac.id](https://ols.ilkom.unsri.ac.id)

2. Login ke akun OLS melalui link berikut:  
   [https://ols.ilkom.unsri.ac.id/login](https://ols.ilkom.unsri.ac.id/login)

3. Jika belum memiliki akun, lakukan registrasi terlebih dahulu melalui link berikut:  
   [https://ols.ilkom.unsri.ac.id/umum/register](https://ols.ilkom.unsri.ac.id/umum/register)

4. Setelah berhasil login, masuk ke dashboard OLS.

5. Pada bagian **Pengajuan**, klik tombol **+ Tambah**.

6. Pilih jenis surat **SURAT KETERANGAN PEMBAYARAN**.

7. Lengkapi syarat pengajuan yang diminta.

8. Syarat yang perlu dilengkapi adalah **Bukti slip pembayaran dari semester awal hingga akhir/saat ini**.

9. Untuk syarat tersebut, mahasiswa perlu menyiapkan link penyimpanan yang berisi bukti slip pembayaran UKT dari semester awal hingga semester akhir atau semester saat ini.

10. Link penyimpanan dapat berupa link Google Drive atau layanan penyimpanan lain.

11. Pastikan link yang dilampirkan dapat dibuka dan dilihat secara publik oleh admin.

12. Jika kamu merupakan mahasiswa terdaftar KIPK, lampirkan link penyimpanan yang berisi **SK KIPK** yang memuat nama kamu.

13. Setelah semua syarat terpenuhi, klik **Ajukan** untuk mengirim pengajuan surat.

14. Tunggu proses pembuatan surat. Biasanya proses ini membutuhkan waktu sekitar **1–2 hari kerja**.

15. Setelah itu, login kembali ke OLS.

16. Periksa status pengajuan surat.

17. Jika status surat sudah **selesai**, buka surat tersebut.

18. Download surat dari OLS.

19. Surat yang diunduh dari OLS sudah berbentuk **PDF**.

20. Pastikan file PDF hasil download disimpan dengan baik untuk diunggah pada form pengajuan kompre.

## Syarat Pengajuan di OLS

Syarat yang diminta pada pengajuan surat ini adalah:

- Bukti slip pembayaran dari semester awal hingga akhir atau semester saat ini.

Namun, yang dilampirkan pada OLS bukan file langsung, melainkan **link tempat penyimpanan file**.

Contoh link yang dapat digunakan:

- Link Google Drive berisi PDF bukti slip pembayaran UKT.
- Link Google Drive berisi SK KIPK untuk mahasiswa terdaftar KIPK.
- Link penyimpanan lain yang dapat dibuka secara publik.

## Untuk Mahasiswa KIPK

Jika kamu merupakan mahasiswa terdaftar KIPK, gunakan **SK KIPK** sebagai dokumen pengganti bukti slip pembayaran UKT.

Pastikan SK KIPK tersebut:

- Memuat nama kamu.
- Tersimpan dalam bentuk file yang jelas terbaca.
- Dapat diakses melalui link penyimpanan.
- Link penyimpanan dapat dibuka oleh publik atau minimal dapat dibuka oleh admin OLS.

## Ketentuan File

- Format file akhir: **PDF**
- Maksimal ukuran file: **1 MB**
- Jumlah file: **1 file**
- Surat diunduh langsung dari OLS setelah status pengajuan selesai.
- Syarat pengajuan pada OLS menggunakan link penyimpanan, bukan upload file langsung.
- Link bukti pembayaran atau SK KIPK wajib dapat dilihat oleh admin.

## Catatan

Pastikan link bukti pembayaran UKT atau SK KIPK dapat dibuka sebelum mengajukan surat di OLS. Jika link tidak dapat diakses oleh admin, pengajuan surat dapat terhambat.

Untuk mahasiswa KIPK, gunakan SK KIPK yang terdapat nama kamu sebagai bukti pendukung pengajuan surat keterangan pembayaran.
