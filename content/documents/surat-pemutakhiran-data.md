# Surat Pernyataan Telah Melakukan Pemutakhiran Data

## Kegunaan

Surat Pernyataan Telah Melakukan Pemutakhiran Data digunakan sebagai pernyataan bahwa mahasiswa telah memastikan data akademik yang tersimpan di UNSRI sudah benar dan sesuai.

Dokumen ini ditandatangani pribadi oleh mahasiswa **tanpa materai**.

## Cara Mendapatkan

Dokumen ini dibuat melalui generator surat pada sistem panduan ini berdasarkan data mahasiswa dan screenshot menu Biodata SIMAK.

Langkah-langkah:

1. Login ke [SIMAK UNSRI](https://akademik.unsri.ac.id).

2. Buka menu Biodata atau langsung akses [halaman Biodata SIMAK](https://akademik.unsri.ac.id/mahasiswa/biodata).

3. Periksa data pada setiap menu Biodata dan pastikan semuanya sudah benar.

4. Jika terdapat data yang salah, ajukan perbaikan melalui [Open Ticket UNSRI](https://openticket.unsri.ac.id) sebelum membuat surat.

5. Lakukan screenshot pada 7 menu Biodata:
   - Data Diri
   - Akademik
   - Alamat
   - Orang Tua
   - Wali
   - Perguruan Tinggi Asal
   - Riwayat Pendidikan

6. Buka generator **Surat Pemutakhiran Data** pada sistem panduan ini.

7. Isi nama, NIM, tanggal surat, dan upload seluruh screenshot menu Biodata.

8. Generate dan download surat dalam format **DOCX**.

9. Rapikan kembali dokumen secara manual jika posisi atau ukuran screenshot masih perlu disesuaikan.

10. Cetak atau print surat pemutakhiran data.

11. Tanda tangani surat secara pribadi tanpa materai.

12. Setelah surat selesai ditandatangani, scan surat tersebut.

13. Ubah hasil scan menjadi file **PDF**.

14. Pastikan file akhir berformat **PDF** dan ukuran file tidak lebih dari **1 MB**.

## Generator Surat

Dokumen ini memiliki fitur generator surat pada sistem panduan.

Field yang perlu diisi:

- Nama
- NIM
- Hari/tanggal surat
- Bulan
- Tahun
- Screenshot Data Diri
- Screenshot Akademik
- Screenshot Alamat
- Screenshot Orang Tua
- Screenshot Wali
- Screenshot Perguruan Tinggi Asal
- Screenshot Riwayat Pendidikan

Field default yang dapat digunakan:

- Fakultas: **Ilmu Komputer**
- Program Studi: **Manajemen Informatika**

## Ketentuan File

- Format file akhir: **PDF**
- Maksimal ukuran file: **1 MB**
- Jumlah file: **1 file**
- Surat harus ditandatangani oleh mahasiswa.
- Tidak perlu materai.
- Hasil scan harus terlihat jelas dan mudah dibaca.
- File akhir dikumpulkan dalam format PDF.

## Catatan

Generator akan memasukkan banyak screenshot sehingga hasil DOCX mungkin perlu dirapikan kembali secara manual sebelum dicetak.

Pastikan data pada setiap menu Biodata SIMAK sudah benar sebelum screenshot. Jika terdapat kesalahan data, ajukan perbaikan melalui Open Ticket UNSRI terlebih dahulu.
